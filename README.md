# Task Management API

This is a simple Express.js API built with TypeScript for managing tasks. It includes:

- **CRUD operations:** Create, Read, Update, and Delete tasks.
- **JWT Authentication:** Secure endpoints with JSON Web Tokens.
- **Data Validation:** Basic input validation using middleware or libraries.
- **Error Handling:** Proper error handling and graceful error responses.

## Technologies Used

- **Node.js**
- **Express.js**
- **TypeScript**
- **MongoDB**
- **Mongoose**
- **jsonwebtoken** (for JWT handling)
- **bcrypt** (for password hashing)

## Installation

1. **Clone the repository:**

   ```bash
   git clone <repository-url>
   ```

2. **Install the dependencies:**

```bash
npm install
```

3. **Run Project:**

```bash
npm run dev
```
